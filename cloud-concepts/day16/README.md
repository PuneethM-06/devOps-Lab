## CLOUD CONCEPTS - DAY 16

## SCALABILITY
- The ability of a system to handle increasing load by adding resources.
- Scale up: It means increase resources of the same machine 
- Scale out: Increase in number of machines / server 

## High Availability
- Host applications in multiple regions and AZ's

## SHARED RESPONSIBILITY MODEL 
- The security and management responsibilities are shared between the cloud provider and the customer

## AWS is responsible for 
1. Data centres and physical security
2. Servers and hardwares
3. Networking infra
4. Storage device
5. Power, cooling etc
6. AZ and regions 

## Customer is responsible for 
1. IAM users and permissions
2. Application code
3. OS
4. Firewall and security groups
5. Data encryption 
6. Database config
7. Secrets and creds
8. Data backups
